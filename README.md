## 当前项目

- 内容工作台与人工发布前的生产辅助
- AI 能力发现、筛选与开源组件评估

- 电商平台数据的只读诊断与优化建议
- 电商 MBTI：主播自评与视频行为证据对照

## 项目进展

更新于 2026-09-07。以下为可公开的阶段摘要；已实现功能与待验证能力分别说明。

| 方向 | 当前进展 | 当前重点 |
|---|---|---|
| 短视频解析与知识库 | 已形成个人日常工作台，支持多段直播聚合、声画证据回看与本场知识整理 | 继续修复证据链问题，验证字幕质量与深度分析稳定性 |
| 小红书内容工作台 | 内容组织与人工发布前工作流已形成可用框架 | 继续进行真实业务流程验证 |
| GitHub AI 能力雷达 | 已接通真实 GitHub 搜索，完成一次历史补扫，并按需筛选少量候选 | 继续完善反馈与观察流程；候选推荐仍需独立评估才能采用 |
| AI 系统运营工作台 | 已具备本地情报、项目进度、能力评估说明与受控同步入口 | 继续验证数据新鲜度与人工确认流程 |
| 项目状态与飞书同步 | 已形成受控同步、回读和人工确认闭环 | 持续验证稳定性并刷新陈旧项目证据 |
| 电商数据诊断 | 只读数据标准化和建议生成原型已形成 | 继续验证真实数据覆盖与分析质量 |
| 电商 MBTI / AI 直播销售能力分析 | 已形成自评与视频诊断双入口体验版，接通本地视频解析，支持证据回看、自评与行为对照及少量切片校准 | 继续验证测量模型、诊断一致性与用户理解；当前不代表成熟人格测评或销售预测能力 |
| AI 视频剪辑工作台 | 已形成 Windows 桌面载体，提供视频导入、方案生成、预览确认与渲染流程 | 继续验证实际素材交付质量与字幕完整性 |

近期新增重点是将视频证据用于主播销售分析，并把剪辑流程整理为可操作的桌面入口。各项目仍按真实验证结果逐步推进，不以体验版或少量样本代替完整业务验收。

代码、运行数据和业务资料会根据公开边界分别保持公开、私有或仅本地，不以“同步”为由扩大公开范围。
