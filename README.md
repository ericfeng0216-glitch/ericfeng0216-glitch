# 你好，我是 Eric

二类电商多品牌操盘手，正在进行 AI 工具产品实践。

## 当前项目

- 短视频内容解析、字幕校准与结构化知识整理
- 内容工作台与人工发布前的生产辅助
- AI 能力发现、筛选与开源组件评估
- 项目状态、知识资产和 AI 日报的本地运营工作台
- 电商平台数据的只读诊断与优化建议
- 电商 MBTI：主播自评与视频行为证据对照
- AI 视频剪辑桌面工作台

## 项目进展

更新于 2026-09-19。以下为可公开的阶段摘要；已实现功能与待验证能力分别说明。详细变化见[项目进展记录](PROJECT_PROGRESS.md)。

| 方向 | 当前进展 | 当前重点 |
|---|---|---|
| 短视频解析与知识库 | 支持整场直播还原、同期声画引用和独立字幕阅读校正，并改善历史任务列表的加载效率 | 继续验证字幕质量、内容还原完整性与模型稳定性 |
| 小红书内容工作台 / 知序 | 已形成独立内容工作台，完成新作品发现、解析、质量检查、飞书写入回读与知识索引的真实单条闭环；支持带来源问答和草稿保存 | 继续验证批量处理、失败恢复和研究内容质量，不把单条成功视为整批完成 |
| GitHub AI 能力雷达 | 已按具体项目需求、现有能力与对照证据筛选候选，保留真实 GitHub 搜索和少量推荐 | 补齐真实任务对照；搜索部分失败、未验证收益和暂缓候选分别记录 |
| AI 系统运营工作台 | 已具备本地情报、项目进度、能力地图、评估说明与受控同步入口 | 持续区分运行时可用、正式采用和已证实业务收益，验证数据新鲜度 |
| 项目状态与飞书同步 | 已形成受控同步、回读和人工确认闭环 | 持续验证稳定性并刷新陈旧项目证据 |
| 电商数据诊断 | 只读数据标准化和建议生成原型已形成 | 继续验证真实数据覆盖与分析质量 |
| 电商 MBTI / AI 直播销售能力分析 | 自评与视频诊断体验版已增加字幕修订、报告版本保留和经审核知识参考，用户页面与内部维护页面分开 | 继续验证候选模型与诊断一致性；当前为本机体验版，未完成公网服务与专业评分验收 |
| AI 视频剪辑工作台 | Windows 桌面流程已加入本地中文字幕生成、同步预览与人工校对确认 | 继续验证实际素材交付质量，保留预览与字幕确认步骤 |

近期重点是贯通内容处理与知识使用、完善报告可追溯性，并按真实任务筛选值得采用的 AI 能力。各项目仍按验证结果逐步推进，不以体验版或少量样本代替完整业务验收。

代码、运行数据和业务资料会根据公开边界分别保持公开、私有或仅本地，不以“同步”为由扩大公开范围。
